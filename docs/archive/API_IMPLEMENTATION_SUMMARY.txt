## 📊 API Endpoints Reference

```
GET  /health           → API status check
GET  /emotions         → List emotion classes (5)
GET  /model-info       → Model details

POST /predict          → Single prediction
   Input:  {"eeg": [...], "audio": [...]}
   Output: {"emotion": "Happiness", "confidence": 0.87, ...}

POST /batch-predict    → Multiple predictions
   Input:  {"samples": [{"eeg": [...]}, ...]}
   Output: {"predictions": [...], "num_processed": 5, ...}
```

## 💻 Usage Examples

### Python (Direct)
```python
from src.inference import EmotionPredictor
import numpy as np

predictor = EmotionPredictor('outputs/attention_fusion_model_best.pt')
eeg = np.random.randn(28, 512)
result = predictor.predict(eeg)
print(f"{result['emotion']}: {result['confidence']:.1%}")
```

### Python (REST API)
```python
import requests
import numpy as np

eeg = np.random.randn(28, 512).tolist()
response = requests.post('http://localhost:5000/predict', 
                        json={'eeg': eeg})
result = response.json()
print(f"{result['emotion']}")
```

### cURL
```bash
curl http://localhost:5000/emotions
curl http://localhost:5000/health
curl -X POST http://localhost:5000/predict \
  -H "Content-Type: application/json" \
  -d '{"eeg": [...]}'
```
